# Stable Desk verification record

September 30, 2026. v1.1 generic demo update. This record covers public-source review and deterministic/browser verification; it does not claim financial assurance, a live market feed or independent production eligibility checks.

The reviewed dataset contains ten organizations, ten primary public sources, ten public-market evidence records, three synthetic evidence examples, three synthetic priorities and decisions, and one new generic baseline. Source titles, URLs and real asset names are original. Every demo relationship has empty relationship-evidence lineage. Validation rejects real-issuer profile modes, promoted demo relationships, mismatched evidence subject/source roles and non-synthetic example decisions.

Executed checks: `npm run validate` passes; nine model tests pass; twenty Chromium browser tests pass (ten desktop, ten mobile). The build produces a validated static app. Packaging compares every ZIP member with build output. The content audit covers current tracked/new text and assets, dist files, unpacked ZIP members and screenshot OCR; Git history is excluded deliberately. See the exact generated reports in `artifacts/`.

Model coverage includes compound evidence search, schema and reference errors, dates/URLs, changed/new context, deadlines, reasoned review state and export round trips. New checks cover legacy-dataset rejection, fictional/public provenance separation and profile-change impact without changing source records.

Browser coverage at 1440 × 1000 and 390 × 844 includes all three views, no page/dialog overflow, search/filters/empty states, source/organization/priority detail, keyboard Escape, comparisons and selection limit, save/reload/export/second-context restore, changed-evidence flags, reasoned review, invalid imports and escaped imported prose. New checks assert fictional demo labels, context-only citations, legacy browser isolation and configurable placeholder labels. Local documentation including the v2 plan serves successfully. Screenshots are regenerated from the generic app, not edited former images; desktop/mobile rendered states are visually inspected separately.

The ten original public pages were opened through the web research tool on the baseline date. Their existence and content scope were reviewed. `check:links` is a separate unauthenticated HTTP client test: all ten executor requests returned `fetch failed`, without HTTP status, and the command exited 2. `artifacts/source-links.json` records that unresolved network coverage. Browser tests verify exact rendered targets; they do not turn client failures into successful reachability results.

Current content/asset replacement removes the former issuer-specific demo rather than renaming its evidence. Earlier Git commits still contain prior content; no force push, history rewriting or deletion occurred. Legacy browser storage is preserved separately; its content is never loaded by the new demo. Generic imports do not accept legacy issuer-specific exports.

Limitations: Safari/Firefox and screen-reader sessions were not tested; source freshness is manual and broad fingerprint warnings are not field-level assumption impact. No real profile, actual token or relationships exist in the demo. No reserves, live quotes, pools, adoption series, authenticated product flow or private terms were verified. Cross-device sync, hosted deployment and scheduled collection are absent. The v2 plan is a proposal only.
